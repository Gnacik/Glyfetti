# Bundled fonts

These fonts are redistributed unmodified under their original licenses (license file next to each font).
Glyfetti does **not** ship modified fonts: missing Polish diacritics are composed at build time
into a local cache (`~/.cache/glyfetti`), never written back into this folder.
